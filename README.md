# Modern Frontend Engineering

A portfolio of frontend learning work, organized by skill area and practical project rather than as a day-by-day journal.

## Portfolio

### JavaScript fundamentals

The [JavaScript exercises](./01-javascript-typescript/fundamentals/exercises/) cover task arrays and objects, loops, functions, callbacks, and array transformations such as `map`, `filter`, and `reduce`.

### React

- [React exercises](./02-react/exercises/) preserve component, state, and effect practice snippets. These are learning drafts, not standalone production components.
- [Task Tracker](./02-react/task-tracker/) is the runnable React + Vite project. Its project README covers features, implementation notes, and setup.

## Repository structure

```text
01-javascript-typescript/
└── fundamentals/
    └── exercises/          # JavaScript fundamentals practice
02-react/
├── exercises/              # React practice snippets
└── task-tracker/           # Runnable React project
03-angular/
└── projects/               # Angular work as it is created
```

The current checkout contains JavaScript practice through Day 11 and React exercises through Day 17. The Angular section is ready for upcoming work. TypeScript, AWS, system design, and testing sections can be added as those projects are completed; they are not represented as completed work here.

## Tech currently represented

- JavaScript
- React
- React Hooks (`useState`, `useEffect`, `useCallback`)
- Vite
